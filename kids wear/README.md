# ADELUX Kids Wear

Upload kids wear product images into this folder.

Supported image formats: JPG, JPEG, PNG, WEBP, AVIF and GIF.

Images added to this folder are automatically listed in the Kids collection on the ADELUX website. Use clear filenames such as `Kids Set 01.jpg` or `Girls Dress 01.png` because the filename is shown as the product name.

Kids wear enquiries are directed to ADELUX on WhatsApp for sizes and pricing.
